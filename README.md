- 🤖 **AI Agents & RAG** — designing agentic workflows and retrieval pipelines for research and information-retrieval tools.
- 🌐 **Full-Stack Engineering** — building complete products end to end, from TypeScript/React frontends to Python backends.
- 📈 **Currently focused on** — MLOps tooling and productionizing agentic systems.
